# PPT Editing Rules

## Content
- Do not invent facts, numbers, names, or claims.
- Preserve the original meaning of slide content.
- Remove leading and trailing whitespace from text.
- Do not silently delete substantive content.

## Formatting
- Preserve the reference deck's overall visual language.
- Avoid unnecessary changes to slide geometry.
- Preserve slide dimensions.
- Preserve existing layouts unless explicitly required.

## Reference
- Use the reference deck as the source of truth for recurring structural and formatting patterns.
- Do not copy reference slide content unless explicitly instructed.
- Treat content differences as expected unless another rule is violated.

## Safety
- Log every mutation.
- Log every assumption.
- Re-run verification after every editing iteration.
- If a change cannot be justified from the rules, input deck, or reference deck, do not apply it automatically.
